# zola
Vibe codding 

## Getting Started

This is a Next.js project with Vercel Web Analytics configured.

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Vercel Analytics

This project includes Vercel Web Analytics for tracking page views and performance metrics. The Analytics component is integrated in the root layout (`app/layout.tsx`).

To enable analytics:
1. Deploy this project to Vercel
2. Enable Web Analytics in your project's Analytics settings on the Vercel dashboard
3. Analytics will automatically start tracking after deployment
